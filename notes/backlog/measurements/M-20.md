# M-20 design measurements (raw lines)

Measured for `notes/backlog/design/M-20.md` on the **local lane** (inference host): 2 x AMD Radeon AI PRO R9700
(gfx1201), TP2, `cap 210 W` read back on both cards by `lane.sh` before every run, ROCm 10.1 (HSA runtime ext 1.32),
kernel 7.0.2-6-pve; links 32 GT/s x16 card side, 16 GT/s x16 at the root ports. u3 container
(`hy4-flash-iqr-v4-u3.rad`), `ngram-placement: ram`, host pool 39000 MiB, prefix cache 16384 MiB (the lane's settings).
Tree `d13d29c82` (base `claude/peaceful-wright-hhqnhi`, no engine change), built per CARDS.md §1.1 with
`/opt/rocm-repeatable` as the HIP compiler and `RAD_HIP_VOPD_REPEATABLE=ON`.

Runs (one server each, `scripts/backlog/lane.sh local 'scripts/backlog/run.sh <tag> <cfg> <phases> RADIANCE_AQL_STAMP=1
RADIANCE_ROUTE_TRACE=…/trace.rt'`, all `server-exit=0`), with a side poller of `/stats` (`vram` units every 0.5 s):

| tag | config | phases |
|---|---|---|
| `m20-coupled03`, `m20-coupled03-2` | `coupled03.yaml` (DFly2) | `c1,c8,lctx1,lctx4` |
| `m20-nospec`, `m20-nospec-2` | `nospec.yaml` | `c1,c8,lctx1,lctx4` |
| `m20-coupled03-hr4g`, `m20-nospec-hr4g` | the same with `gpu-headroom-mib: 4224` (3,304 fewer slab slots: the residency lever) | `c1,c8` |

The tools (`rtrace.py`, `stamps.py`, `align.py`, `evalm2.py`, the DMA bench) are in `notes/backlog/measurements/M-20-tools/`.
