# X-04: persistent prefix store (`prefix-cache-dir`), with X-06's global suffix cache

The PR cherry-picks dartree `a8400909 9e883a39 46c77e35 e0976a0a 5cb4c2ad bab7361b`. It is an operations feature
with no kernel change, so the bar is: the default (store off) is unchanged, and with the store on a conversation
survives a restart, matches a cold run exactly, stays within its bounds, and survives a damaged store.

- before = base `f2a0c7efbfd817fecad89cdbdae5b0ab347c82ad` (Merge #262); after = `4d9b09d318b30331889f5e5726111c6669f966a9`
  (that base merged into the PR head `08f02b4b`). Diff between them = the PR's 30 files exactly.
- Machine: inference host, 2 x Radeon AI PRO R9700 (gfx1201), TP2, `power1_cap` read back 210 W on both cards
  before every run, 170 GiB RAM. Built 2026-11-25 with `/opt/rocm/llvm/bin/clang++` (AMD clang 24.0.0) as CXX and
  HIP compiler, `-DRAD_WITH_HIP=ON -DRAD_GPU_TARGETS=gfx1201`. Both arms were built the same way, before the
  repeatable-HIP-compiler rule of 2026-11-26.
- Container `hy4-flash-iqr-v4-u3.rad` (138093449672 B); config `scripts/backlog/nospec.yaml` as rendered by the local
  lane (`prefix-cache-mib: 16384`, `checkpoint-interval: 1984`, `prefix-resume: nearest`).

## 2. Store on: across a restart

One server at a time on the lane (`lane.sh --gpu local`). The server is started and given the requests, then
stopped with SIGTERM, which is a clean stop and flushes the store. Requests: P1 = `long_prompt(72000, 3)` (24608
tokens); P2 = P1 + `long_prompt(3000, 44)` (25408 tokens, the conversation's next turn). Settings: greedy, top-5
logprobs, 64 tokens. Hash = sha256 of the text.

| server | request | TTFT s | from where | text / top-5 logprobs vs the cold P1 / P2 |
|---|---|---|---|---|
| A, `prefix-cache-dir: S` (empty) | P1 | 6.602 | cold (0 cached) | `e5c1a8b05103`, reference |
| A | P1 again | 0.471 | memory hit, 23808 tokens | identical, max diff 0.0 |
| A | P2 | 0.523 | memory hit, 23808 tokens | `a1fc3cf57561`, reference |
| A stops | | | | `at stop: wrote 6398 item(s), 842.95 MiB, in 0.72 s` |
| B, same S (after the restart) | P1 | 1.063 | **disk**: `read 6151 entries (24604 tokens) and a snapshot, 377.22 MiB, from disk in 0.099 s`; hits 23808, `prefix_store_paged_in_total` +6151 | identical, max diff 0.0 |
| B | P2 | 0.498 | disk: 201 more entries (804 tokens), 11.19 MiB | identical, max diff 0.0 |
| C, no store | P1 | 7.253 | cold | identical |

After the restart, P1's TTFT falls from 6.6-7.3 s to 1.06 s, the first request of a fresh server. The answer and
its top-5 logprobs are bit-identical to the cold run and to the in-memory hit. That is the item's own check:
restored hit == in-memory hit, including the conversation snapshot (window + CONV) that the disk read restores.
B opened the store in 0.003 s: 6384 entries and 14 snapshots indexed, payload read only on first use.

## 3. Bounds and damage

- **Disk cap** (`prefix-cache-dir-mib: 128`, P1 then P2): `at stop: wrote 425 item(s), 127.97 MiB ... 5973 left out
  by the cap`; `du -sb` = 134234543 B (128.0 MiB). Without a cap the default bound is the host tier plus the
  checkpoint store (18.45 GiB here). RAM is not extra: pages come into the existing host-tier slots
  (`prefix-cache-mib`). When that tier is full, the oldest copy the store also holds is dropped first.
- **Flipped bytes** (one byte XORed every MiB of every segment, then server D on that store): `entry ... did not read
  back whole (I/O or checksum); dropped` for each damaged entry. The hit was cut to 28 tokens and the prompt was
  prefilled (TTFT 7.096 s). The answer was identical to cold. The server served on and stopped cleanly.
- **Foreign / garbage store** (random bytes in place of `index.rpx`, and a directory under another key): `... was
  written under another key and is discarded`, then `index.rpx is damaged; starting empty`. The foreign directory
  was removed, the answer was identical to cold, and the stop wrote a fresh store (796.05 MiB).
