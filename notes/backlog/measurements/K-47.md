## Clause 2: `cast` faster (profile-ops, rank 0, pf6 + pf20 run, same prompts both arms)

| arm | cast calls | cast ms | cast us/call | run total (sum of ops) |
|---|---|---|---|---|
| base | 2808 | 255.8 | 91.1 | 11591.7 ms |
| head | 2808 | 71.3 | 25.4 | 11482.3 ms |

(`profagg.py`'s own row for base reads 1404 calls / 130.0 ms / 92.6 us: it prints the cast row of one table; the call count
is the same on both arms.) Cast per call 3.6x faster; the op total falls 109 ms (0.9 %) over the two prefills.
Small casts in the decode-step table are unchanged (6.3-6.9 us base, 6.3-6.8 us head: narrow-row copies there are tiny).

Author's kernel-level timings (`rad_memcpy_2d_async`, µs per launch, median of 9 batches, 2 passes): indexer 128 B x 32768
36.3|36.7 -> 4.8|4.9; 128 B x 32768 spitch 256 40.1|40.4 -> 8.9|8.8; 64 B x 32768 59.7|59.5 -> 3.3|3.3; 1024 B x 1536 3.8|3.9 -> 3.0|3.0;
25 MiB 128 B x 204800 143.7|143.7 -> 32.8|33.7; 25 MiB 1280 B rows flat; 4 MiB with 4096 B rows 4.0|4.1 -> 4.3|4.4 (about 0.4 us slower,
a wide-row control; not visible in any served number below).
