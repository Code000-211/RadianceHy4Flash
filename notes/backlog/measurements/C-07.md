# C-07 — the unconditional export measured: no gain there; the card stays open

The item (issue #95) asks to drop DFly2's **empty** context pass, which costs two barrier rounds
(~5–20 us a step), behind `draft_pass < 0`. What was built and measured was the export declared
unconditionally; on this config the pass is not empty, so that arm buys nothing. The gated arm the
item actually asks for is still unmeasured — the card stays open.

## What it says

The pass the head drops is not empty here: it carries `mla_row_front` and two `add_rmsnorm`s, and the
head does its store with `r4dchain_kv_store` instead. So the work moves rather than disappears — 58.0
us of pass kernels out, 36.7 us of store in, and the draft pass as a whole ends up 29 us (0.58 %)
slower at c8 and 84 us (2.12 %) slower at c1. End-to-end is parity: c8 −1.1 % median, c1 +5.9 % median,
both inside this box's spread.

The call site is what makes it fire: `arch/hyv4flash/hyv4flash_dfly.h:962` calls
`rad_drafter_no_context_pass(b)` for every dfly2 build, where the item's premise is a drafter whose
pass *issues nothing* (`hyv4flash.cpp:1113-1119`, `draft_pass < 0`). A dfly2 drafter with a cache has
work in that pass, so the export must be gated on that condition, not declared unconditionally.

## What this record is — and why the card stays open

The review is right that this measured the wrong arm: the branch declared the export unconditionally,
while the item's change is the gated one (`draft_pass < 0` issues nothing). The gated change has never
been measured, so the card stays open; this note is evidence for that attempt, not a close.

What the run does establish: on a dfly2 drafter **with** a cache, the unconditional export is not a
win — the pass it drops is not empty (`mla_row_front` 42.6 us and two `add_rmsnorm` 8.5 + 6.9 out,
`r4dchain_kv_store` 36.7 in), the pass is 29 us (0.58 %) slower at c8 and 84 us (2.12 %) at c1, and
end-to-end sits inside this box's spread. The metric the item's bar uses (kernel-exclusive time)
cannot show barrier-round savings at the 29 us scale either way, which is the other reason the close
did not hold.

Raw rows: **not retained** — the run directory (`/tmp/c07-out`) and its script are gone with the
measuring session; the per-round rows in the table above are every number it produced that bears on
the item.

A gated-arm measurement on a lane is what would decide the card: the call behind `draft_pass < 0`, the
same three-round interleaved run, and a metric that can see the barrier rounds.
