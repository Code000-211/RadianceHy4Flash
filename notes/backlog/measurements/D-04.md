Six server sessions (A-e2e1, B-e2e1, B-e2e2, A-e2e2, A-e2e3, B-e2e3), each with three probe rounds (n = 9 a side).
c1: one request, 256 tokens; c8: 8 × 256; c1s 64; c8s 8 × 48; pf2 / pf6 / pf20 are prefill-only probes. Decode is
sampled (T 0.9, seeded), so the accepted tokens a step vary run to run within each tree.
