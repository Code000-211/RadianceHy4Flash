## What the code commit changes

1. **The barrier** — `core/runtime/rank_barrier.{h,cpp}`: a rank waits with a bounded spin (10,000
   relaxed loads, exposed as `spin_budget()`) and then parks in `std::atomic::wait` on the arrival
   counter, instead of taking the mutex and condition variable on every one of the ~73 steps a
   256-token DFly2 decode takes. `parks()` exposes a relaxed count of how many times a rank actually
   parked, which is what makes the "spin briefly, then park" contract checkable from outside.
2. **CCD pinning is deleted, not fixed** — `core/runtime/thread_pin.{h,cpp}` and its two call sites in
   `core/engine.cpp` are gone. It measured −14.9 % tok/s as an opt-in arm, had no test, no
   `CMakeLists.txt` entry (so the file was never compiled), and its documentation described pinning
   the code did not implement. An opt-in arm that loses 15 % has no reason to exist; it is withdrawn.

## The test, and what it catches

`tests/rank_barrier_test.cpp` — 4 cases, 11 checks, registered as ctest #112:

- `a_late_rank_is_parked_in_the_futex_after_a_bounded_spin` — reads `parks() >= 1`
- `the_spin_before_parking_is_bounded` — asserts `spin_budget() <= 100000` and that the waiter's own CPU
  time stays under 8 ms while it waits
- `an_arrival_that_completes_the_barrier_does_not_park`
- `an_aborted_barrier_releases_a_parked_rank`

Run against deliberate breakage, not just against good code:

- **against the merge base** `cf11ed50` it does not compile: `'class rad::RankBarrier' has no member
  named 'parks'` — the API it asserts on does not exist there.
- **against a whole-wait spin variant** (`kSpin` raised to 40,000,000, then restored) three checks fail:
  `parks() >= 1` (it never parks), the CPU-time bound (24.75 ms burned in the wait) and
  `spin_budget() <= 100000`.
- timing probe of the real barrier: wall 25.15 ms, **cpu 0.03 ms**, parks=1; the spin variant:
  wall 25.14 ms, **cpu 24.75 ms**, parks=0. Parity alone cannot see that difference, which is why the
  CPU-time and `parks()` assertions exist.
